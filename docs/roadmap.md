## Critério para uma tarefa ser considerada concluída

Uma tarefa só deve ser marcada como concluída quando:

1. estiver implementada ou, para tarefas de design, documentada;
2. puder ser verificada;
3. não bloquear o progresso principal;
4. estiver registrada em commit;
5. a documentação relevante estiver atualizada.
